
# 🍫 Chocolate Sales Analysis Dashboard | Power BI

## 📌 Project Overview
This is my Power BI learning project, created by following a YouTube tutorial by Chandu. I used the dataset shared on his YouTube page and recreated the Chocolate Sales Dashboard to gain practical experience in data analytics and Power BI.

## 🎯 Project Objectives
- Analyze overall chocolate sales performance.
- Track total sales, boxes sold, and shipments.
- Identify sales trends over time.
- Compare sales performance across different products.
- Analyze top-performing products and salespeople.

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization

## 📊 Key Learnings
- Data cleaning and transformation using Power Query.
- Creating calculated measures using DAX.
- Building interactive dashboards.
- Analyzing sales trends and performance.
- Presenting business insights through data visualization.
